# cSCCmouseProject
This Github repository contains the code that was used for the analysis and generation of results presented in the following manuscript: 
Roth, K., Coussement, L., Knatko, E. V., Higgins, M., Steyaert, S., Proby, C. M., ... & Dinkova-Kostova, A. T. (2021). Clinically relevant aberrant Filip1l DNA methylation detected in a murine model of cutaneous squamous cell carcinoma. EBioMedicine, 67, 103383.
